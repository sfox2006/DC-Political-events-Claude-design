About

What this is

A curated listing of upcoming DC politics and ideas events, including in-person, hybrid, and online, across the spectrum — libertarian, conservative, progressive, foreign policy, and abundance/YIMBY. It is updated as new events are announced.

Window
The list shows upcoming events from today through about the next 7 years, in Eastern Time. The calendar pages about 3 months ahead and marks those days.
Sources
Public organization calendars, newsletters, and social posts. Details are checked against the source pages.

Add this page to your home screen to open it like an app. On iPhone or iPad: Share, then Add to Home Screen. On Android or desktop Chrome: Install app, or the browser’s install menu. Refresh loads the latest published events.
